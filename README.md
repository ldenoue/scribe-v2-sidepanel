# QuickScribe

Extension to make youtube transcripts readable with punctuations, paragraphs and chapters.

The extension also provides a narrowly scoped message bridge on AppBlit's QuickScribe pages. It accepts `SCRIBE_YOUTUBE_PLAYER_REQUEST` messages, fetches YouTube player metadata from the user's browser, and replies with `SCRIBE_YOUTUBE_PLAYER_RESPONSE` using the same request ID.
The extension uses two small deep learning AI models in your browser to restore punctuations and find chapter headlines.
